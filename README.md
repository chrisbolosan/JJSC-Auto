## Assigned Project
Product System - Auto Parts

## Project Description
We are building a web application for an auto parts company that lets customers order parts online and helps warehouse staff manage inventory and shipping. The system connects to an existing product database and uses a new database to track live stock and customer orders.
## Initial Project Goals
The initial project requirements involve building a custom online catalog for customers to select products, calculate total costs, and securely process credit card payments. The system must interface with an existing legacy product database and a new database to manage inventory and customer orders. It also requires warehouse interfaces for printing packing lists, invoices, and shipping labels, as well as updating stock when new shipments arrive. Finally, an administrative interface is needed to configure weight-based shipping rates and search completed or pending customer orders.
